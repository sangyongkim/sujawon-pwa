수문곡선의 분리방법

개요

  • 수문곡선(hydrograph) : 임의단면(지점)에서 유출에 의한 하천유량의 시간적변화를 나타내는 곡선
  • 수문곡선의 성분 : 첨두유량, 첨두시간, 지체시간, 기저시간, 변곡점, 감수곡선의 변곡점으로 해석
  • 총유출 수문곡선은 직접유출(지표면유출 + 중간유출)과 기저유출의 합으로 구성
  • 유출 해석을 위해 총유출 수문곡선(직접유출 + 기저유출)에서 직접유출을 분리시켜야 함

수문곡선 분리방법

  • 정확한 수문곡선 분리를 위해서는 유역의 지질 수문학적 특성이 고려되어야 하나 해석적 규명방법이 마련되지 않아 개략적인 방법 이용

주지하수 감수곡선법

  1. 해당 관측점에 대한 주지하수 감수곡선을 과거 수문곡선으로부터 산정
  2. 절차
    • 과거 수년간 연속적인 유량 기록을 일련의 수문곡선으로 작성
    • 각 수문곡선의 감수곡선을 택하여 logQ−tlogQ-tlogQ−t 관계곡선 작성
    • 각 logQlogQlogQ 최저값에 접선 작성
    • 접선을 다시 선형좌표로 표시해 주지하수 감수곡선 작성
    • 실제 수문곡선의 감수부와 주지하수 감수곡선을 겹쳐서 두 곡선이 만나는 점 결정
    • 수문곡선의 상승부 기점A와 직선으로 연결하여 수문곡선 분리
  3. 특징
    • 과거 수문 자료를 이용해 가장 신뢰성이 높고 물리적 의미가 있음
    • 처리할 자료가 많고 복잡

수평직선 분리법

  1. 상승부 기점(A)으로부터 수평직선 그어 분리
  2. 특징
    • 가장 간단한 방법으로 실무에서 많이 사용
    • 호우지속기간 동안 기저유량의 변화가 크지 않다고 가정

N-day 법

  1. 상승부 기점(A)으로부터 N일 후 유량 지점까지 직선을 그어 분리

  2. 특징
    • 비교적 간단
    • 유역면적 일정하면 기저시간도 일정하다는 가정

수정 N-day 법

  1. 특정 강우 바로 전의 지하수 감수곡선은 어느정도 체감하는 효과 고려
  2. 절차
    • 감수곡선을 첨두유량발생시간까지 연결( C )한 후 N일 후 유량 지점까지 CB3‾\overline{CB_3}CB3​​를 연결해 직접유출과 기저유출 분리
  3. 특징
    • 비교적 간단
    • 강우로 인한 지하수위 상승은 지표면 유출에 비해 비교적 완만해 지하수 감수곡선은 첨두부까지 그대로 유지
