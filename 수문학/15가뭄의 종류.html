가뭄의 종류

개요

  • 정의 : 장기간에 걸쳐 강수량이 부족하여 물 부족 현상이 나타나는 것
  • 특성 : 우리나라 가뭄특성은 벼농사와 결부, 평균 10년에 1회 발생

가뭄의 종류

  1. 기상학적 가뭄
    • 일정기간동안 무강우일수가 지속되어 강우부족으로 인해 발생하는 현상
    • 건조함의 정도를 예년치와 비교로 가뭄의 정도를 평가
    • 해당지역의 독립적인 개념으로 다른 지역과의 비교는 곤란
    • 가뭄지수 : PDSI, SPI(표준강수지수)
  2. 농업적 가뭄
    • 농작물 생육을 위한 용수부족에 의해 발생하는 현상
    • 기상상태, 성장단계별, 토양깊이별 필요수분량의 부족에 따른 가뭄
    • 가뭄지수 : 작물수분지수(CMI), 토양수분지수(SMI)
  3. 수문학적 가뭄
    • 댐, 저수지, 하천, 지하수 등 공급가능한 용수 감소에 의해 발생하는 현상
    • 기상학적 및 농업적 가뭄보다 늦게 나타남
    • 가뭄지수 : 지표수공급지수(SWSI), 수정지표수공급지수(MSWSI), 실시간가뭄지수(RDI)
  4. 사회⋅\cdot⋅경제적 가뭄
    • 물부족으로 인간의 경제활동에 피해를 주는 현상

가뭄지수

  • 가뭄에 기여하는 인자들을 지수화하여 표현
  1. 표준강수지수(Standardized Precipitation Index, SPI)
    • 가뭄은 강수량의 부족에 의해 시작된다는 것에 착안하여 개발
    • 시간단위별(3,6,9,12개월) 강수부족량 계산 → 개개 용수공급원이 가뭄에 미치는 영향 산정
    • 강수량만을 고려하는 단순한 방법으로 다양한 지속시간에 대하여 산정
  2. 파머가뭄지수(Palmer Drought Severity Index, PDSI)
    • 장기간의 이상 수분 부족 현상
    • 가뭄심도를 수분부족량과 수분부족기간의 함수로 표현
    • 기후가 상이한 두 지역에 대한 지역적 편차 고려
    • 잠재증발산량 추청 후 실제 강수량과 기후학적 필요강수량의 차를 계산한 후 기후특성인자 계산, PDSI 지수 산정
    • 가뭄의 출현시기가 지체될 수 있음
    • 복잡한 지역에 따라 정확도가 떨어짐
  3. 지표수공급지수(Surface Water Supply Index, SWSI)
    • 가뭄에 미치는 인자를 통계학적으로 해석, 유역기여도를 가중치로 사용
    • 물공급 여건을 반영하는 수문학적 가뭄지수
    • 지표수공급 반영 가능성을 평가
    • 수원에 물이 많으면 가뭄으로 평가하지 않음
    • 장점 : 각 유역의 독특한 물공급 조건을 대표
    • 단점 : 산정과정에서 유역간 비교가 제한
  4. 수정지표수공급지수(Modified SWSI, MSWSI)
    • 복잡한 지형조건과 다양한 물공급 특성을 가진 우리나라의 수문학적 가뭄을 평가하기 위하여 SWSI 를 보완
  5. 작물수분지수(Crop Moisture Index, CMI)
    • 주(week)마다 작물 상태를 감시하기 위한 농업적 가뭄지수
    • 단시간의 수분공급량을 반영
    • 장점 : 잠재적인 농업가뭄을 확인할 수 있음
    • 단점 : 장기간의 가뭄관측의 적용은 곤란

가뭄 대책

  1. 긴급대책 : 매년 가뭄을 예상하고 단계별 대책 수립
    • 사전대책 : 기상분석, 가뭄상습지 관리, 용수확보 대책추진, 용수절약운동
    • 대책단계
      1. 가뭄우려단계 : 양수장비 배정, 기술지원, 중장비 지원
      2. 가뭄확산단계 : 가뭄상습지 지하수 탐사
      3. 가뭄심화단계 : 중앙정부지원, 용수원 개발, 다목적댐의 비상용수공급
    • 해갈단계 : 영농대책, 안정대책
  2. 항구대책 : 극심한 가뭄이 들더라도 피해가 없도록하는 대책
    • 구조적 대책 : 신규댐 축조, 대체수자원확보, 광역상수원 확충
    • 비구조적 대책 : 용수절약 및 절수, 기존수리시설물 연계운영, 가뭄관리시스템 구축
    • 정책적 대책 : 농촌용수개발, 수리시설 재편, 보강사업의 활성화

국내 가뭄 모니터링 현항

  1. 기상청
    • PDSI, SPI → 가뭄판단지수
    • 일별가뭄평가 : 매우 가뭄, 가뭄, 정상, 습함 4단계
  2. 한국농어촌공사
    • SPI, 강수량, 저수율 분석결과 → 가뭄단계 조정
    • 최근 SMI, RDI, IADI 사용
  3. 한국수자원공사
    • SWSI → 국내 실정에 맞는 보완한 MSWSI 적용
    • 가뭄단계 : 9단계 구분

가뭄 모니터링 체계개선을 위한 시사점

  1. 각 기관에서 필요목적에 따라 가뭄모니터링 수행
  2. 각 기관에서 PDSI, SPI를 기본적으로 제공하나 경과 상이 → 신뢰성 검토, 일관성 유지 필요
  3. 국가차원의 가뭄모니터링은 기상학적 가뭄지수에 의존 → 가뭄전망에는 유용하나 실적적인 가뭄상황 진단시 현실성 떨어짐
  4. 실질적 대책 수립시 수문학적 가뭄지수 유용
  5. 기후변화에 대한 가뭄 감시체계와 예측에 의한 대비 시급 → 가뭄 예경보 시스템 개발 필요

가뭄모니터링 시스템 개발

  1. 가뭄모니터링을 위한 데이터 구축
  2. 가뭄 재해통합관리시스템 개발
  3. 실시간 가뭄발생 모니터링
  4. 장단기 가뭄전망
  5. 가뭄 예경보 시스템 구축

국가 가뭄재해통합시스템 세부요소

  1. 가뭄재해 피해액 산정기법
  2. 가뭄재해 예경보시스템
  3. 통합가뭄진단 평가시스템
  4. 가뭄통합운영 플랫폼

평가

  1. 각 기관에서 운영목적에 맞는 각각의 가뭄지수를 통해 모니터링 실시
  2. 중앙재난관리기관 또는 가뭄재해정보센터에서 가뭄지수를 종합적으로 분석 → 가뭄재해 예방, 대비, 복구 단계에서 중대한 의사결정을 할 필요 있음
