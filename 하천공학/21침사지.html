침사지

개요

  1. 정의 : 개발지역에서 침식되어 유송되는 토사를 자연적 인위적으로 침천 퇴적시킬 목적으로 설치되는 유사저류시설
  2. 목적
    • 토사침식 증가 억제하여 하천, 호소 영향 최소화
    • 유출토사 및 쓰레기 등 이물질을 침전시켜 준설, 제거하여 오염부하량 제거, 홍수피해경감
    • 저류지 상류에 설치하여 저류지 토사퇴적 감소시켜 저류용량 감소 방지

침사지 종류

  1. 설치목적에 따라
    • 재해방지침사지 : 하류지역 토사재해 방지
    • 환경침사지 : 공공수역 수질보전
  2. 기능에 따라
    • 간이침사지 : 현장에서 임시로 축조한 높이 1.5m이하의 소규모 침사지로 통상 하루이내 침사 목적
    • 임시침사지 : 전체 공사기간동안 침사 목적
    • 영구침사지 : 공사기간에는 침사 역할, 공사 후 다목적 이용(경관, 위락, 저류, 지하수함양)
  3. 저류방식에 따라
    • 완전저류 : 비교적 적은 호우시 전량 저류하고 큰 호우시 비상여수로 통해 월류
    • 흐름저류 : 침사지내 천천히 흐르는 상태에서 유사 침전. 재현기간 큰 호우사상, 대규모배수지역에 적합

침사지 설치 위치

  • 개발지역 직하류부
  • 공사용 기계 이동에 장애 없는 위치
  • 준설활동이 용이한 지점
  • 인접 하천 본류에는 설치하지 않음

침사지 구성

  1. 유입조절부
    • 유입홍수량이 와류, 편류 없도록 배분
    • 침전효율증대
    • 필요시 가로벽(소단, 웨어) 설치
  2. 홍수조절부
    • 홍수조절 역할
    • 유입수문곡선, 홍수조절량, 유출 조절부 규모에 의해 결정
  3. 토사조절부
    • 침전부
      • 홍수를 잔잔하게 유지, 토사 침전 유도
      • 홍수량, 설계포착대상 입경, 설계포착률 고려
      • 회전류 억제 위해 흐름방향 길게 설치
    • 퇴사저류부
      • 침전부 아래 침전토사 저류공간
      • 토사유입량, 설계포착률, 준설주기 고려
  4. 유출조절부
    • 침사지 수위, 유출량 제어
    • 침사지 및 홍수량 설계기준에 따라 규모, 형식 결정
    • 웨어, 방류관, 연직관, 주여수로 등으로 구성

소요용량결정

퇴적유사량 산정

  • 퇴적유사량 = 토양유실량 x 유사전달률 x 침사지 포착률/침사지내 퇴적토 중량

토양유실량(생산토사량) 산정방법

  1. 원단위법
    • 경험자료에 의한 토사유출량 원단위법 사용(일본 실측자료)
    • 지표의 다양성, 유역특성 고려불가하여 신뢰성 부족
  2. 범용토양손실공식(USLE)
    • 표준밭자료 대규모 수집해 개발
    • 재해영향평가시 사용
    • A(ton/ha) = R x K x LS x C x P = R x K x LS x VM
    • A : 강우침식인자 R의 해당기간 중 단위면적당 토양침식량
    • R : 강우침식인자
    • K : 토양침식인자
    • LS : 지형인자
    • C : 토양피복인자
    • P : 토양보존대책인자
    • VM : 토양침식조절인자 (C,P 의 높은 임의성으로 대신 사용)

유사전달률

  • 유역에서 침식되어 나오는 생산토사량과 유역의 한 지점을 통과하는 유출토사량의 비

포착률

  • 총 유입유사량과 퇴적유사량의 비
  • 유사 이동이 저지 등에 의해 차단되는 비율
  • 실무에서는 100% 로 간주
