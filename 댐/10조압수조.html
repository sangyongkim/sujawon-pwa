조압수조(surge tank)

개요

  • 조압수조는 발전소, 펌프장 등 관수로 내 급격한 압력변화, 유속변화 시 수격작용을 감쇄, 제거하기 위한 수조 형식의 조절기구
  • 수격작용
    • 뉴턴의 제2법칙 F=ma=mdVdtF=ma=m\frac{dV}{dt}F=ma=mdtdV​
    • 밸브의 급폐쇄시 dt,Vdt, Vdt,V 는 0 , FFF 는 무한대, 관에 발생하는 압력도 무한대
    • 실제로 밸브를 순간적으로 조작할 수 없어 압력이 무한대는 아니나 상당히 커짐

조압수조의 기능

  • 수격작용 → 압축흐름 → 조압수조 유입
  • 수조내 물의 진동으로 압력 감쇄
  • 수조 내 단면적과 진폭은 반비례
  • 진폭크기, 진동시간을 고려하여 최적단면 결정
  • 설계초점 : 단시간 내에 진동이 안정되는 경제적인 단면 결정

조압수조의 수리설계조건

  • 전부하 차단조건 : 전부하의 순간차단시 surging의 최고수위가 수조의 천단을 월류하지 않을 것
  • 전부하 급증조건 : 전부하의 급증시 surging의 최저수위가 수압관의 천단표고보다 높을 것
  • 안정조건 : 수조내 미소진동 발생시 평형상태로 복원되어 안정성을 가질 것
  • 감쇄조건 : 부하변화에 중첩되어도 이상surging이 발생하지 않을 것

조압수조의 종류

  1. 단동 조압수조(simple surge tank)
    • 단면적이 큰 1개의 종관으로 보통 사용하며 상단은 대기에 노출
  2. 제수공 조압수조(orifice surge tank)
    • 수조저부 orifice 를 통하여 수압관과 연결된 형태로 조압수조 유입량을 조절하여 압력파의 수압관으로 전달 제어
  3. 차동 조압수조(differential surge tank)
    • 이중수실구조로 수조내 관경과 동일한 연직원통을 갖고 있는 형태
    • 바닥에 내부수실에서 외부수실로 물이 이동하도록 오리피스 설치
    • 수격압 상승시 물의 이동 : 수압관 → 내부수실 → 외부수실로 순간적 반응
    • 수격압 감소시 물의 이동 : 외부수실 → 내부수실 → 수압관
  4. 수실 조압수조(chamber surge tank, closed tank)
    • 수조의 상부를 폐색하여 공기쿠션으로 수충작용 흡수
    • 좁은 연직수실 + 단면적이 큰 큰 수실로 구성
    • 좁은 수실의 수면상승은 신속하나 넓은 수실은 진동폭이 크지 않음
