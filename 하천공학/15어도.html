어도

개요

어도의 정의

  • 하천을 가로막는 수리시설물에 의해 이동이 차단 또는 억제된 물고기 등의 회유를 목적으로 만든 수로 또는 장치

어도 설치 기준

  • 어도를 설치하여야 하는 하천 : 국가, 지방, 소하천
  • 예외규정
    • 어류의 서식이 현저히 없음.
    • 하천의 수질이 서식에 적합하지 않음
    • 건천구간
  • 어도 설치할 경우 실시설계 완료 전 수산연구기관과 협의 의무화

어도의 설치시 고려사항

  1. 수리시설물의 필요성과 낙차 축소 등의 검토
  2. 좋은 어도 충족 조건
    • 회유어가 어도 입구 이외의 장소에 모이지 않아야 함
    • 어도에 진입한 회유어가 신속, 쉽고 안전하게 회유할 수 있어야 함
    • 어도 통과 후 안전하고 신속하게 하천상류로 회유할 수 있어야 함
    • 어류의 손상이나 피로를 피할 수 있어야 함
    • 간단한 구조, 유지관리 쉽고 비용절감
  3. 대상 동물 설정
  4. 대상 동물의 회유시기 : 동절기를 제외한 3월 ~ 11월

어도의 종류와 특징

1. 풀 형식

  1. 계단식
    • 장점 : 간단한 구조, 시공 유지관리 용이, 경제적
    • 단점 : 어도내 유황 불균일, 풀내 순환류 발생, 유영력 및 도약력이 좋은 어종만 이용
  2. 아이스하버식
    • 장점 : 어도내 유황 균일, 넓은 하천에 유용, 별도의 어류 휴식 공간 불필요
    • 단점 : 계단식보다 복잡한 구조, 현장시공 어려움
  3. 버티컬슬롯식
    • 장점 : 좁은 장소에 설치 가능
    • 단점 : 복잡한 구조, 큰 공사비, 어도내 수심 20cm 이상시 용수 손실 큼, 경사가 완만하지 않은 경우 유속이 빨라 다양한 물고기의 이동이 어려움

2. 수로 형식

  1. 도벽식
    • 장점 : 간단한 구조, 시공 유지관리 용이, 경제적
    • 단점 : 어도 내 유황 불균일, 어도 내 수심 20cm 이상시 용수 손실 큼. 유속이 빨라 적정 수심 유지 어려움, 유영력 좋은 어류만 이용
  2. 인공하도식
    • 장점 : 모든 어종 이용 가능
    • 단점 : 설치 장소의 확보가 어려움. 길이가 길어져 공사비 과다

3. 조작 형식

  • 상하류 낙차가 큰 경우, 방조제처럼 외조위가 높을 때, 다른 형식 적용이 곤란한 경우 인위적으로 시설 작동
  • 갑문식, 엘리베이터식, 리프트식, 트럭식 등
  • 장점 : 어종의 유영력과 도약력에 무관하여 다양한 어종의 이동 가능, 댐 방류량 적은 경우와 저수지 수위변동이 큰 경우에도 적용 가능
  • 단점 : 공사비, 운영비 과다

어도 세부 설계

설계 절차

  1. 자료수집
    • 수리시설물 제원
    • 수문 및 수리
    • 동식물 자료
    • 하천이용 및 기타자료
  2. 설계조건 설정
    • 생태유지 기본유량
    • 어도위치
    • 설계유량, 어도 갯수
    • 어도설계 기본 하상고
    • 어도설계 기본 수위
    • 생물의 한계유영속도
    • 어도 건설비용
  3. 기본설계
    • 형식, 평면배치, 일출구부 설계, 제원 개략 설계
  4. 상세설계
    • 어도 폭, 깊이
    • 어도 입출구부 설계
    • 어도 경사, 길이
    • 격벽 간격, 제원
    • 최대유속, 월류수심
    • 비월류 격벽 풀규모
  5. 유지관리계획 설계
    • 홍수 전후 어도관리
    • 회유성 어류 이동시기의 유지관리
    • 시공 후 어류의 이용효율 판정

형식 선정시 고려사항

  • 이용 어종의 다양성과 대상 어종의 유영력
  • 수리시설물의 규모(넓은 하천 : 아이스하버식, 좁은 하천 : 버티컬슬롯식, 도벽식)
  • 낙차(1m 이내 : 수로식, 5m 이내 : 풀식, 5m 이상 : 조작식)
  • 상류 수위 변동폭, 공사비, 유지관리비, 휴식 풀의 필요성

세부설계요소

  • 폭은 갈수기 유량 기준
  • 경사 1/20 이상 (버티컬슬롯식 1/25)
  • 내부수심 : 수로형식 0.2m 이상, 풀형식 0.7m 이상
  • 월류수심 10cm (버티컬슬롯, 도벽식 20cm)
  • 신축 및 시공이음 설치로 균열방지
  • 유인 수로의 설계는 어도 이외로 흐르는 여유수량 활용 고려
  • 어도 설치 후 효율평가를 통한 검증 필요

어도의 이용효율 평가

  • 모니터링 시기 : 3~10월 기준, 산란기 추가 조사
  • 전문가에 의한 조사 : 3~6월 매 2주일마다 실시
